## Software Description

### Short Summary (140 characters):
Free, 100% client-side PDF utility suite with zero server uploads, irreversible redaction, target compression, and WebRTC touch signing.

### Full Description:
PDFCraft is a modern, privacy-focused PDF utility platform engineered to run entirely inside your browser's local memory. Unlike traditional online PDF tools that upload sensitive files to remote cloud servers, PDFCraft processes everything client-side with zero network uploads.

Key Features:
* **True Irreversible Redaction:** Permanently removes underlying text characters and objects from the document stream, rather than merely drawing a visual black box.
* **Target Size Compression:** Compress documents down to exact portal limits (50 KB, 100 KB, 200 KB, 300 KB, 500 KB) using iterative binary-search quantization.
* **P2P Touch Signing:** Scan a QR code from a laptop to sign naturally with your phone's touchscreen via an encrypted direct WebRTC DataChannel.
* **PDF Merge & Split:** Reorder, rotate, delete, or batch-split documents into separate files or ZIP archives with preserved document integrity.
* **AES-256 PDF Encryption & Decryption:** Lock documents with industry-standard passwords and decrypt owner files locally.
* **ATS Resume Studio:** Single-page vector resume builder with local real-time keyword matching against job descriptions.
* **Zero Account Required:** No registrations, no watermarks, no subscriptions, and zero daily quotas.
