## Description:

Traditional web PDF utilities run bloated Python/C++ Poppler containers on remote AWS/GCP clusters, charging engineers $15/month subscriptions and creating massive GDPR/data-compliance headaches.

**PDFCraft** re-imagines document processing by pushing modern web standards to the limit:
* **Zero Backend Storage:** Built with `@cantoo/pdf-lib`, `pdfjs-dist`, HTML5 Canvas, and Web Workers.
* **Direct WebRTC P2P Touch Signing:** Zero servers involved. Desktop hosts a peer, phone connects over WebRTC DataChannel via PeerJS and STUN, transfers touch vectors, and receives instant bidirectional ACK.
* **Military-Grade Redaction:** High-DPI canvas flattening with text operator eradication, `/Annots` object deletion, and metadata purges.
* **Target Size Squeezer:** In-memory binary-search quantization that guarantees file sizes strictly under government portal limits (50KB, 100KB, 200KB, 300KB, 500KB).
* **AES-256 Web Crypto:** Industry-standard PDF encryption and owner unlocking.

Free, MIT-licensed, zero telemetry, and works completely offline.
